# AIラボ

Claude Proの余力で、仕事と生活に役立つ成果物を継続的に育てる仕組み。
設計の背景と全体仕様は [docs/SPEC.md](docs/SPEC.md) を参照。

## 使い方（PC上のClaude Codeでこのフォルダを開いて実行）

| コマンド | いつ | 内容 |
|---|---|---|
| `/setup` | 最初の1回 | 保管庫の場所を確認し、専用フォルダとテンプレートを作る |
| `/weekly-discover` | 週の初め | テーマ候補10件と推薦1件を週次ノートに作る |
| `/weekly-build <番号>` | 承認後 | 選んだテーマを設計・実装・検証する |
| `/weekly-record` | 開発後 | 開発記録を週次ノートと成果物台帳に書く |
| `/feedback` | 随時 | 評価を取り込み、次回の提案に反映する |

## 構成

```
CLAUDE.md            常に守る規則（書き込み範囲・承認・機密）
config/scope.yaml    対象領域と優先度、配分、上限
config/local.yaml    このPCでの保管庫パスなど（Git管理外。/setup が作る）
templates/           保管庫の専用フォルダに作るノートのひな形
.claude/skills/      上記コマンドの定義
docs/SPEC.md         仕様とロードマップ
```

状態（バックログ・週次ノート・成果物台帳・プロフィール）はすべてObsidian保管庫の専用フォルダに置く。
このリポジトリには仕組みだけを置き、業務情報は置かない。

## 対象領域や優先度を変えるとき

「家庭のテーマも2割入れて」のように指示すれば、Claudeが `config/scope.yaml` を書き換える。
