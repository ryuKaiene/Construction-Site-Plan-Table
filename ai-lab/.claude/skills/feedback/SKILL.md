# 評価の取り込み

## 1. 評価を集める

- 会話で伝えられた評価、または週次ノートの「評価・フィードバック」欄を読む。
- 足りない項目だけ尋ねる：点数（1〜5）、実際に使ったか、一言。長い聞き取りはしない。

## 2. 記録する

- 成果物台帳の評価履歴に日付つきで追記する（利用者の記述は書き換えない）。
- 段階を更新する：1回使った→「試用」、2週間後も使っている→「定着」、使われていない→利用者に確認のうえ「廃止」。

## 3. 分析して反映する

- 点数が3以下、または使われなかった場合、原因を分類する：課題設定の誤り／解決方法の誤り／使い勝手／導入の手間／時期尚早。推測の場合は推測と書く。
- `プロフィール.md` の「好まれる傾向・避ける傾向」を更新する。
- 関連するバックログの確度を上下させる。改善要望は育成テーマとしてバックログに追加する。
- 点数が4以上なら、次に伸ばす案を2〜3件、育成テーマとして追加する。

## 4. 未評価の確認

`no_feedback_days` を超えて評価のない試用中の成果物があれば、使っているかどうかだけ一言尋ねる。
