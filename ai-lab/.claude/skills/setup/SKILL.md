# 初回セットアップ

## 1. 環境の確認

- 保管庫を探す。候補：macOSは `~/Library/Mobile Documents/iCloud~md~obsidian/Documents/`、Windowsは `%USERPROFILE%\iCloudDrive\iCloud~md~obsidian\`。見つからなければ利用者に尋ねる。
- 見つからない、またはクラウド上のセッションである場合は、PC上で実行するよう伝えて終了する。
- NotebookLM連携のツールが使えるか確認する（使えなくても続行し、`notebooklm: false` とする）。

## 2. 保管庫の構造を読む（変更しない）

- 最上位フォルダの一覧と命名規則（番号付き・日本語・英語など）を見る。
- 1on1記録など会議記録のフォルダを特定する。
- 専用フォルダ名を既存の規則に合わせて提案し、**利用者の承認を得てから** 作成する。

## 3. 作成するもの

- `config/local.yaml`（`config/local.example.yaml` を元に）
- 専用フォルダ内：`週次/` `バックログ/` `成果物/` と、`templates/` から `プロフィール.md` `余力キュー.md`
- `.claude/settings.local.json`：専用フォルダ外の保管庫への書き込みを拒否する権限規則と、メール送信・公開系ツールを常に確認する規則。利用できる規則の書式は現行の設定仕様を確認してから書く。

## 4. プロフィール初版

保管庫を一度だけ広く読み、`プロフィール.md` を埋める。量が多い場合はフォルダごとに軽量モデルの補助エージェントに要約させ、要約だけを受け取る。読めなかったファイル（iCloud未ダウンロードなど）は件数を記録する。

## 5. 完了報告

作成したファイルの一覧、専用フォルダの場所、プロフィールの要点を伝え、プロフィールの誤りを訂正してもらう。その後 `/weekly-discover` を案内する。
